# Small presentation library

`tokens.css` defines color and font configuration. `components.css` defines pills, section labels, folder tabs, notched ticket frames, rounded containers, dividers, circular controls and diagram routes. SVG implementations live in `../index.html`; v3 reveal primitives live in `../engine-v3.js`. [manifest.json](manifest.json) maps component IDs, uses, variants and source paths.

All page-specific composition overrides live in `../presentation.css`. Do not adjust the immutable v3 reference for styling changes. Display font: self-hosted Faculty Glyphic, SIL OFL 1.1. Exact Classe font remains unconfirmed. The two reference illustration slots deliberately use explicit placeholders while publication rights are unresolved.
