## Source fidelity and limits

- Source state is recorded in `local source-version record (retained outside the repository)`. Two pre-existing modified files were present before this task: `web/src/modules/rainyAlley/runtimeGeometry.ts` and `tests/rainy-alley-map.test.ts`. They were preserved; this task makes no game-source edits. Captures therefore represent the current local working build, not a claim of a clean remote-release build.
- Source versions / frames are kept at normal speed. Curated video is H.264/yuv420p/30fps with fast-start MP4 and no audio. The raw screencast is silent; no audio was invented. Looping repeats with a reset cut, not a claim of seamless world continuity.
- Crops remove browser-free outer gameplay toolbar/footer while retaining the action and useful contextual labels. Real darkness, normal prompts and event UI remain.
- Current floor artwork is selected by `web/src/modules/map/enhanced-artwork.ts` with original lossless/PNG fallbacks in `map/artwork.ts`. L0 and L−1 enhanced bitmaps are 1671×941 and runtime registers them to the unchanged 1672×941 world; preview SVG follows that registration.
- The retained graybox is 1448×1086 and includes its original route annotations. It is a historical design reference, not current collision evidence. Other process-preview assets have been removed from this review scope.
- Supporting folders inspected: `level_design/rainy_alley/source/` (v09 SVG + geometry + object data), `level_design/chapter4/` (approved art/collision/data), and `level_design/chapter5/source/v07/` (real warehouse grayboxes/geometry). They are references only. No exact locked Rainy Alley v0.4 graybox file was found or relabeled; that optional comparison is not used.
- Local review graphics use independent SVG compositions for explanation. They are not final approved presentation layouts, measured heights or new game assets.
